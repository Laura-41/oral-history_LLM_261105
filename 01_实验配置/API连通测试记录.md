## 2026-11-05：Qwen接口可用性异常

在运行六份Demo受控事件包对照时，`cuc/qwen` 出现持续读取超时：

- `GET /v1/models` 正常，模型列表仍包含 `cuc/qwen`；
- 同一终端、同一密钥调用 `cuc/deepseek` 的最小中文请求成功；
- `cuc/qwen` 的最小中文请求等待120秒后超时；
- `DEMO-P03`、`DEMO-P04`、`DEMO-P06` 的受控事件包请求均未生成结果文件；
- 此前的Qwen最小中文、JSON和六类标准单句实验已经成功，因此不能据此认定模型ID、密钥或本地路径错误。

当前判定为学校平台Qwen生成服务临时不可用或严重拥堵，记作**接口可用性失败**，不写成“模型能力较差”。Qwen六包对照暂缓，是否产生超时请求费用由研究者另行核对平台使用日志。本阶段不再自动重试Qwen。

两者出现相同类型误判，说明下一轮实验必须加入：

1. 韩礼德六类过程的可操作定义；
2. “物质过程”与“行为过程”的正例和反例；
3. 参与者角色枚举；
4. 过程规范化要求；
5. 六份Demo中的少样本示例；
6. 固定JSON Schema和自动校验。
