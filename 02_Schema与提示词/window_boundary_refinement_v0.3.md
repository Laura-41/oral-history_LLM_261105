# 连续窗口边界规则 v0.3 补充：停止合并条件

本补充与v0.2共同使用，用于防止把相邻但已经形成不同结果的经历过度合并。

即使人物和时空大体连续，出现以下情况时也必须开始新的一级事件：

1. 前一段已经形成可独立概括的稳定经历或阶段性结果；
2. 叙述从长期、反复、日常状态转入一次性、突发、例外遭遇；
3. 行动目标发生明显变化，例如从维持家庭生活转为观看、躲避或应对外来危险；
4. 新的外部施事者介入并造成新的结果；
5. 后一段即使删去前一段的日常背景，仍能独立构成有触发、过程和结果的完整经历。

“同一年龄、同一地点附近、叙述相邻”不能单独作为合并理由。不得只保留窗口中最显著的最终遭遇，而吞并此前已经完整成立的长期经历。

边界判断应先比较阶段性结果：

- 长期劳动、学习、任职或训练形成稳定生活／身份／能力，是一个可独立一级事件；
- 随后由新消息、新目标、新施事者或突发危险触发的遭遇，是新的一级事件；
- 新事件内部的听说、前往、看到、受袭、逃脱和心理影响仍按v0.2合并为一条经历链。

输出前再检查一次：每个一级事件应各自拥有不同的核心目标或阶段性结果；既不能把一个完整经历拆成多个小过程，也不能把两个结果不同的完整经历压成一个事件。
