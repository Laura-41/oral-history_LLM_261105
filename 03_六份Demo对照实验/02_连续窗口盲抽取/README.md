# 连续窗口盲抽取最小验证

本阶段只使用一个连续窗口和一次DeepSeek请求，验证模型能否在不知道事件数量与边界的情况下自主拆分候选事件。

- 固定窗口：`CRT-01-S0018`至`CRT-01-S0027`，共10个连续片段；
- 模型输入：`inputs/WINDOW-01.json`；
- 人工参考：`answer_key/answer_key.json`，仅在模型完成后评价，运行脚本不会读取；
- 预期只用于验证事件拆分、片段边界、单事件Schema和逐字证据；
- 本轮不扩展到六份Demo全文，也不批量处理其余54份。

运行前须在当前终端保留 `CUC_API_KEY`，然后执行：

```bash
python3 scripts/window_pilot_test.py --model cuc/deepseek --window WINDOW-01 --boundary-version v0.3
```

程序只发送一次请求，不自动重试。模型结果保存后，再将模型事件数和片段边界与隔离的人工参考进行比较。

## 当前结果

2026-11-05已完成一次DeepSeek请求。技术结构通过，但模型抽取6个事件，人工参考为2个；存在背景事件误纳和一级事件过度切分。本阶段停止扩展更多窗口，详细判断见 `测试记录.md`。

v0.3在 `WINDOW-01` 上恢复为2个事件，事件数量、片段边界和主导类型均与人工参考一致。第3步仅增加一个泛化窗口 `WINDOW-02`：陈海峰组织印书馆罢工离厂，以及随后失业并重新就业，共13个连续片段。
