# 连续窗口边界规则 v0.4 补充：触发事件与人物行动合并

本补充与v0.2、v0.3共同使用，目标是在过度切分和过度合并之间保持中等粒度。

## 1. 叙事功能优先于表面严重程度

原文中某个过程即使严重、具体或包含死亡，也不自动构成独立一级事件。先判断它在受访者经历主线中的叙事功能。

如果某个他人遭遇主要用于解释受访者随后为何反抗、离开、参加组织或改变选择，并且二者在同一地点、同一阶段连续发生，那么该遭遇应作为后续人物行动的触发阶段，或与前面的持续压迫背景合并，不单独建立事件节点。

例如，“长期受剥削和处分—同伴遭虐待死亡—工人提出意见受压制—组织罢工离厂”可以采用以下任一种中等粒度：

1. 将“长期剥削＋同伴受虐”合并为压迫经历，再单列罢工行动；
2. 保留长期剥削，将“同伴受虐＋组织罢工”合并为由触发到反抗的经历；
3. 将上述全部合并为一次“受压迫后组织罢工离厂”的完整经历。

不得仅因为“同伴死亡”内容严重，就在它只承担罢工触发原因时单独建立一级事件。

## 2. 保留不同阶段结果

合并触发因素和人物行动后，仍要保留结果明显不同的后续生活阶段。罢工离厂、失业困苦、重新就业分别可能形成不同阶段性结果：

- 离开原单位并使生产任务受影响；
- 一段时间无业、无收入并陷入生活困难；
- 找到新工作、收入恢复并能够支援家人。

失业与重新就业可以根据叙述紧密程度合并为一段“失业后再就业”经历，也可以分成两个相邻事件；但不得为了追求细粒度，把每项生活细节继续拆成独立事件。

## 3. 与既有规则的平衡

1. v0.2继续负责把同一突发经历内部的听说、前往、看到、受袭、逃脱和心理影响合并。
2. v0.3继续负责把长期稳定经历与随后目标、施事者、结果不同的突发经历分开。
3. v0.4负责把仅作为因果触发的他人遭遇并入相邻人物主线，避免因严重细节而过度切分。

输出前检查：每个候选是否具有可独立查询的受访者经历结果；如果候选只回答“为什么发生后面的行动”，而不能独立说明受访者完成了什么经历，应与相邻事件合并。
