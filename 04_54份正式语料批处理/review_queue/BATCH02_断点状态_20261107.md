## 四、根因：终端脚本熔断时返回 0，重试循环被误判为成功

`scripts/run_batches_in_terminal.sh` 的 `else` 分支虽打印了「中断（退出码 3）」并 `break`，但 `break` 后脚本最后一条命令是 `echo`，**整体进程退出码为 0**。于是外层

```bash
for i in $(seq 1 15); do AUTO_CONTINUE=1 bash ... && { echo "完成"; break; }; done
```

在第一次熔断后就走进 `&&` 分支提前 `break`，终端显示「BATCH02 完成 / 批次已完成」，实际并未完成。

**修复（2026-11-07，仅改 shell 退出码控制流，不碰任何标注逻辑／提示词／Schema／校验器／结果文件）**：新增 `FAILED_CODE`，在 `else` 分支记录 `$code`，脚本末尾 `exit "$FAILED_CODE"`。

- `bash -n` 通过；
- 用不存在的批次模拟熔断（`DRY_RUN=1 ... BATCH99`），外层拿到退出码 **2**（修复前为 0）；
