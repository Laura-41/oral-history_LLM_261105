## 一、先回忆：这两套词表本来是干什么用的

- **之前那套**：给「人读 + 进图谱」用的，问的是 **这句话在讲故事里起什么作用**。
- **现在这套**：给「机器无损切开 Word 原文」用的，问的是 **这句话在文件里是哪一块**。

**不是谁对谁错，是两种视角**，而且两边互相都装不下对方。所以这不是「选一套丢一套」的题，是「要不要两列都留」的题。

### 1.1 `segment_type`（原文片段是什么类型）

| 真实原文（都取自你的语料）                     | 之前（人工 7 值）                                   | 现在（机器 6 值）                        |
| --------------------------------- | -------------------------------------------- | --------------------------------- |
| 「记者：先把3支队情况讲一下。」                  | `INTERVIEWER_PROMPT` 记者提问                    | `INTERVIEWER_PROMPT` ✅ **唯一完全一致** |
| 「3支队呢，新四军刚成立的时候，一共四个支队，江北（是）4支队…」 | `EVENT_EVIDENCE` 事件证据                        | `ORAL_TESTIMONY` 口述正文             |
| 「我补充一点。」                          | `BACKGROUND` 背景                              | `ORAL_TESTIMONY` 口述正文             |
| 「就从家庭讲起吧。」                        | `NARRATOR_COMMENT` 讲述人自评                     | `ORAL_TESTIMONY` 口述正文             |
| 「他是新四军参谋长，挂一个名，」                  | `OFF_TOPIC` 跑题                               | `ORAL_TESTIMONY` 口述正文             |
| 「嘉宾名称：陈海峰…嘉宾身份：出生于1912年8月4日…」     | `DOCUMENT_NOTE` 文档注                          | `BIOGRAPHICAL_PROFILE` 人物小传       |
| 「袁国平：（1906—1941），湖南宝庆人…」          | `DOCUMENT_NOTE` 文档注                          | `EDITORIAL_NOTE` 编者注／脚注           |
| 「　00：01：00」                       | **旧表没有专门格子**，只能塞 `DOCUMENT_NOTE`／`UNCERTAIN` | `RECORDING_TIMESTAMP` 录音时间码       |
| 空白／无法归类的一行                        | `UNCERTAIN` 未定                               | `UNCLASSIFIED_BODY` 未分类正文         |

**实测规模**：之前 689 片段 → `EVENT_EVIDENCE` 289、`DOCUMENT_NOTE` 226、`INTERVIEWER_PROMPT` 104、`BACKGROUND` 51、`OFF_TOPIC` 11、`NARRATOR_COMMENT` 8；现在 BATCH02 679 片段 → `ORAL_TESTIMONY` 308、`RECORDING_TIMESTAMP` 223、`INTERVIEWER_PROMPT` 110、`EDITORIAL_NOTE` 28、`BIOGRAPHICAL_PROFILE` 9、`UNCLASSIFIED_BODY` 1。

**一句话看懂**：

- 现在这套把之前的 4 个「正文细分格」（事件证据／背景／跑题／自评）**合成 1 个大桶** `ORAL_TESTIMONY`；
- 又把之前的 1 个 `DOCUMENT_NOTE` **拆成 3 个格**（小传／编者注／时间码）。

**只留一套各会丢什么**：

- 只留旧表 → 223 条时间码没有专门位置，将来「按录音时间定位原文」这条查询就废了；
- 只留新表 → 你手工分出的 289 条「真在讲事件」和 51 条背景、11 条跑题全糊成一团，覆盖率审计只能证明「原文都进来了」，证明不了「事件证据被正确识别」。
